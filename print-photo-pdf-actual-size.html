Print a photo PDF at actual size: home or print shop

By Mohamed Elatabany · Updated 5 October 2026

To keep photo dimensions unchanged, print the exported PDF on matching paper using Actual size or 100% scale. “Fit” changes the page size to suit the printable area and can change every photo’s dimensions.

Prepare the PDF on iPhone

  1. Arrange photos in Photo Print at the dimensions you need.
  2. Choose the paper size the printer or shop will use. A4 and US Letter are different page sizes.
  3. Leave sufficient page margins. The PDF can contain correct measurements and still be clipped by a printer’s unprintable edges.
  4. Save or share the PDF from the output screen. Send that file to the shop, rather than a screenshot of the preview.

The print settings that matter

In Adobe Acrobat, select Size under Page Sizing & Handling and choose Actual size. Adobe explains that this prints without scaling; content that does not fit can be cropped. See Adobe’s page-size printing instructions.

A checklist to send to your print shop

Please print this PDF on the paper size specified in the file, at actual size / 100%, one PDF page per sheet. Please do not fit, shrink or enlarge the page. Print one test sheet first so I can measure the photo dimensions before the full run.

Measure the first sheet

For a 2 × 2 inch photo, check both sides: each should measure 50.8 mm. If it measures 48 mm, the scale is about 94.5% (48 ÷ 50.8 × 100). Correct the print settings before printing the rest; changing the layout to compensate can hide the underlying problem.

Can I print without AirPrint?

Yes. PDF export lets you print from a computer or a shop. Direct printing from Photo Print uses AirPrint. Exporting preserves the layout, but the final printer settings and paper still determine the physical result.
