# photoprint-site

The public pages for **Photo Print: Size & Layout**.

- `privacy.html` — App Store Connect *Privacy Policy URL*
- `support.html` — App Store Connect *Support URL*

These files are **generated**, not hand-edited: run `python3 tools/build_site.py <this-dir>` in the app repo.
The privacy policy's source is `docs/PRIVACY_POLICY.md` there.

No cookies, no analytics, no external requests.
