# photoprint-site

The public pages for **Photo Print: Size & Layout**.

- `privacy.html` — App Store Connect *Privacy Policy URL*
- `support.html` — App Store Connect *Support URL*
- `guides.html` and the four how-to pages it lists — printing guides (passport/ID photos,
  exact-size 4 × 6, several photos on one page, wrong-size prints)
- `sitemap.xml`, `robots.txt` — all crawlers allowed, including GPTBot, OAI-SearchBot and ChatGPT-User

`privacy.html` is generated by `python3 tools/build_site.py <this-dir>` in the app repo from
`docs/PRIVACY_POLICY.md` there — edit the policy there, never here. Every other page (index,
support, the guides, sitemap, robots) is hand-written in this repo.

No cookies, no analytics, no external requests. (The JSON-LD blocks are structured data, not scripts.)
